# tinysystems.io

The website. Static files, generated by a small Go program, served by nginx.

- `main.go` — the generator: `content/` + `templates/` + `static/` → `dist/`
- `content/docs/*.md` — the manual (front matter: title, description, section, weight)
- `content/blog/*.md` — field notes (front matter: title, description, date, author)
- `templates/` — Go html/template layouts
- `nginx.conf` + `redirects.inc` — serving config; old-platform 301s live in the include

Build locally:

```
go run .
open dist/index.html
```

CI builds `ghcr.io/tiny-systems/website` on every push to main; flux deploys it.
